Fundamentals

What is a Network?

A network is a collection of two or more interconnected devices (computers, servers, printers, etc.) that share resources, data, and communication channels.

Networks allow devices to exchange information using defined protocols and rules.

  • File and resource sharing
  • Internet access for all connected devices
  • Centralized data storage and backup
  • Collaboration and communication

What is an IP Address?

An IP (Internet Protocol) Address is a unique numerical identifier assigned to every device on a network. It serves as the device's location address for sending and receiving data.

  • IPv4: 32-bit format (e.g., 192.168.1.1)
  • IPv6: 128-bit format (e.g., 2001:0db8::1)
  • Used for routing packets across networks
  • Can be static (fixed) or dynamic (assigned by DHCP)

What is a MAC Address?

A MAC (Media Access Control) Address is a unique hardware identifier burned into every network interface card (NIC) by the manufacturer. It operates at the Data Link layer (Layer 2).

  • Format: 48-bit (12 hex digits)
  • Example: AA:BB:CC:DD:EE:FF
  • First 6 digits = OUI (manufacturer ID)
  • Last 6 digits = device-specific ID
  • Used within a LAN for frame delivery

What is a Public IP?

A Public IP address is globally unique and assigned by your ISP (Internet Service Provider). It is visible to the entire internet and allows your network to communicate with external servers and services.

  • Assigned by your ISP (e.g., Jio, Airtel, BSNL)
  • Unique across the entire internet
  • Required for hosting websites, games, servers
  • Uses NAT to share among private devices
  • Can be changed by restarting router (dynamic)

What is a Private IP?

A Private IP address is assigned to devices within a local network (LAN) by your router. These addresses are not routable on the internet and are reused across different home/office networks.

  • Class A: 10.0.0.0 – 10.255.255.255
  • Class B: 172.16.0.0 – 172.31.255.255
  • Class C: 192.168.0.0 – 192.168.255.255
  • Assigned automatically via DHCP
  • Devices share one Public IP via NAT

Network Types

🏢

LAN (Local Area Network)

Covers a small geographic area like a single building, office, or campus. High speed and low cost.

1–10 Gbps ~1 km range
🌍

WAN (Wide Area Network)

Spans large geographic areas such as cities, countries, or the entire world. The internet is the largest WAN.

150 Mbps – 10 Gbps Unlimited range
🏙️

MAN (Metropolitan Area Network)

Covers a city or large campus. Bridges LANs across a metropolitan area with high bandwidth.

100 Mbps – 10 Gbps ~5–50 km range
📱

PAN (Personal Area Network)

Connects devices around a single person. Used for Bluetooth, USB, and wearable connections.

1–100 Mbps ~1–10 m range

Network Devices

📡

Router

Directs data packets between different networks using IP addresses. Connects LAN to WAN/Internet.

🔀

Switch

Connects devices within a LAN. Uses MAC addresses to forward data to the correct destination port.

🌐

Hub

Broadcasts data to all connected devices. Less efficient than a switch — largely obsolete.

🛡️

Firewall

Monitors and filters incoming/outgoing network traffic. Protects against unauthorized access.

📶

Access Point (AP)

Provides wireless connectivity to a wired network. Enables Wi-Fi access for devices.

🔌

Modem

Modulates/demodulates signals for data transmission over phone lines, cable, or fiber.

🔓

Gateway

Acts as a protocol converter between different network types. Entry/exit point of a network.

🔄

Bridge

Connects two separate network segments at the data link layer. Reduces collision domains.

Key Device Functions

Data Routing

Routers select the best path for packets across networks using routing tables and protocols (OSPF, BGP).

Frame Switching

Switches forward frames based on MAC address tables, creating dedicated collision-free paths.

Packet Filtering

Firewalls inspect packet headers and payloads to allow or block traffic based on rules.

Signal Conversion

Modems convert digital data to analog signals and back for transmission over various media.

Wireless Bridging

Access Points extend wired networks wirelessly, managing association, authentication, and encryption.

Protocol Translation

Gateways convert data between different protocols, enabling communication across dissimilar networks.
