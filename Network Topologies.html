What is Topology?

The word "Topology" comes from two Greek words: topos (place) and logos (study). So topology literally means "the study of placement."

In Simple Words

Topology is simply how things are arranged or connected. In networking, it describes how devices (like PCs, printers, servers) are physically or logically laid out and how data moves between them.

Physical Topology

How devices are physically wired or connected with cables.

Physical topology is about the actual hardware — the cables, switches, and how they are laid out in a room or building. It answers the question: "Where are the devices and how are they wired?"

  • Uses real cables (Ethernet, fiber optics)
  • Shows the shape of the network (bus, star, ring, etc.)
  • If a cable is cut, the physical layout breaks
  • Easy to see and touch
Example: In an office, 5 PCs are connected to one switch with 5 Ethernet cables. The physical layout looks like a star — all cables go to the center switch.

▶ Animation

Logical Topology

How data flows through the network, regardless of how cables are arranged.

Logical topology is about how data actually travels through the network. Even if cables are arranged one way, data might flow differently. It answers: "How does data move from A to B?"

  • Not about cables — about the data path
  • Determined by network protocols and devices
  • Two networks can look the same physically but work differently logically
  • Invisible — you can't see it, only observe it
Example: Two phones sharing a photo via Bluetooth. There's no cable — data travels wirelessly through the air. The physical topology is "no wires," but logically the data flows directly from Phone A to Phone B.

Physical vs Logical — Key Difference

Physical = What you can see and touch

Logical = What you can only observe in data flow

Types of Network Topologies

There are several ways to arrange devices in a network. Each type has its own strengths and weaknesses.

Bus Topology

All devices share a single central cable. Data travels along the cable; if it breaks, the whole network goes down.

▶ How Data Flows

Star Topology

Every device connects to a central hub/switch. If one cable fails, only that device is affected. Easy to manage.

▶ How Data Flows

Ring Topology

Devices form a closed loop. Data passes through each node until it reaches the destination. One failure can break the ring.

▶ How Data Flows

Mesh Topology

Every device is connected to every other device. Very reliable (if one link fails, data takes another path) but expensive.

▶ How Data Flows

Tree Topology

A hierarchy of star networks. A root node connects to groups, which connect to devices. Good for large networks.

▶ How Data Flows

Hybrid Topology

Combines two or more topologies. Flexible and scalable — used in real-world large networks.

Transmission Methods

Transmission methods define how data is sent from one device to another across a network. They determine the direction and flow of communication.

Simplex

Data flows in one direction only. The sender can only send, and the receiver can only receive. No feedback is possible.

Real-Life Example

TV broadcasting, radio, keyboard input to computer — you send or receive, never both.

Half-Duplex

Data can flow in both directions, but not at the same time. Devices take turns sending and receiving.

Real-Life Example

Walkie-talkie — "Press to talk, release to listen." Only one person speaks at a time.

Full-Duplex

Data flows in both directions simultaneously. Both devices can send and receive at the same time.

Real-Life Example

Phone calls — both people can talk and hear at the same time. Fastest and most efficient.

Session 3

What is Casting?

Casting is the method used to send data to one or more destinations on a network. It determines who receives the data you send.

Unicast (One-to-One)

Data is sent from one sender to one specific receiver. This is the most common type of communication on networks.

▶ How It Works

Real-Life Example

Browsing a website — your PC connects to one specific web server to load a page.

Broadcast (One-to-All)

Data is sent from one sender to all devices on the network. Every device receives the message whether it needs it or not.

▶ How It Works

Real-Life Example

TV channel broadcasting — the signal goes to every TV in range, whether you're watching or not.

Multicast (One-to-Many)

Data is sent from one sender to a specific group of receivers — only the ones who subscribed or are interested.

▶ How It Works

Real-Life Example

Live video conference — data is sent only to participants, not to everyone on the network.

Session 4

Endpoint & End User

Every network communication involves devices and people. Understanding endpoints and end users tells you what is connected and who is using it.

What is an Endpoint?

An endpoint is any device that can send or receive data on a network. It's the "end" of a communication path — where data starts or finishes.

Common Endpoints

Computers, smartphones, tablets, servers, printers, smart TVs, IoT devices — anything connected to a network.

What is an End User?

The end user is the person who actually uses the device or service. They are the human behind the endpoint — the reason the network exists.

Examples of End Users

A student browsing the web, a gamer playing online, an employee on a video call — any person using a networked device.
