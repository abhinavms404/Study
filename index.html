Port Number Ranges

Network ports are divided into three main categories based on their usage

Well-Known Ports

0 - 1023

Reserved for standard services like HTTP (80), HTTPS (443), SSH (22), and FTP (21). These ports require root/admin access to use.

Registered Ports

1024 - 49151

Assigned by IANA for user applications. Common examples include MySQL (3306), PostgreSQL (5432), and RDP (3389).

Dynamic/Private Ports

49152 - 65535

Temporary ports for client connections. Used for ephemeral communication and not assigned to any specific service.

Network Protocols

Understanding the core protocols that power internet communication

TCP

Transmission Control Protocol

Connection-oriented, reliable protocol. Ensures data delivery with error checking, flow control, and packet reordering.

Reliable • Ordered • Verified
UDP

User Datagram Protocol

Connectionless, fast protocol. No guaranteed delivery, but minimal overhead. Perfect for real-time applications.

Fast • Lightweight • Stateless
ICMP

Internet Control Message Protocol

Used for diagnostic and error reporting. Essential for ping and traceroute commands to test network connectivity.

Diagnostics • Ping • Errors
DNS

Domain Name System

Translates domain names to IP addresses. Uses both UDP (port 53) for queries and TCP for zone transfers.

Port 53 • UDP/TCP • Resolution
DHCP

Dynamic Host Configuration Protocol

Automatically assigns IP addresses to devices. Uses UDP ports 67 (server) and 68 (client) for communication.

Port 67/68 • Auto-Config
