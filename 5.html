📡 What is the OSI Model?

Understanding the OSI Model

The OSI (Open Systems Interconnection) Model is a reference framework developed by the ISO (International Organization for Standardization) in 1984. It divides network communication into 7 distinct layers, each with specific responsibilities.

Think of it as a universal language for networking — it allows different systems and technologies to communicate by following a standardized set of rules at each layer.

  • Provides a universal standard for network protocol design
  • Enables interoperability between different vendors and technologies
  • Breaks down complex communication into manageable layers
  • Each layer communicates only with the layer directly above and below it

7

Application Layer

PDU: Data

Human Interaction Layer — This is the layer that users interact with directly. It provides network services to end-user applications.

Key Functions

📧 Email Services
🌐 Web Browsing
📁 File Transfer
🖥️ Remote Access
💬 Chat / Messaging
🖨️ Network Printing

Examples

Email (SMTP, IMAP, POP3) Web Browsing (HTTP/HTTPS) File Transfer (FTP, SFTP) DNS Resolution Telnet / SSH

Protocols

HTTP HTTPS FTP SMTP POP3 IMAP DNS SNMP SSH
6

Presentation Layer

PDU: Data

Data Translation Layer — Acts as a translator between the application and network. Converts data formats so applications can read them regardless of internal representation.

Key Functions

🔄 Data Translation
🔐 Encryption
🔓 Decryption
🔤 Character Encoding
📦 Data Compression
📂 Decompression

Examples

SSL/TLS Encryption JPEG, GIF, PNG Image formats ASCII, UTF-8 Encoding MPEG Video Compression ZIP File Compression

Protocols

SSL TLS JPEG MPEG GIF PNG ASCII EBCDIC
5

Session Layer

PDU: Data

Session Management Layer — Establishes, manages, and terminates connections (sessions) between applications. Handles dialogue control and synchronization.

Key Functions

🤝 Session Establishment
🔄 Session Maintenance
🔑 Authentication
🛡️ Authorization
❌ Session Termination
📊 Synchronization

Examples

NetBIOS Sessions RPC (Remote Procedure Call) PPTP (VPN Tunneling) Video Conferencing Sessions Database Connections

Protocols

NetBIOS RPC PPTP SAP SDP
4

Transport Layer

PDU: Segments (TCP) / Datagrams (UDP)

End-to-End Delivery Layer — Ensures complete data transfer between end systems. Provides reliable or unreliable delivery depending on the protocol used.

Key Functions

✂️ Segmentation
📊 Flow Control
❌ Error Control
🔗 Connection-Oriented (TCP)
📡 Connectionless (UDP)
🔄 Multiplexing

Examples

TCP — Reliable, ordered delivery (Web, Email) UDP — Fast, lightweight (Streaming, Gaming, DNS) Port Numbering (80, 443, 53...) Three-way Handshake (SYN, SYN-ACK, ACK)

Protocols

TCP UDP SCTP DCCP

Network Layer

PDU: Packets

Logical Addressing & Routing Layer — Handles routing of data packets across different networks. Uses logical addresses (IP) to identify source and destination.

Key Functions

📍 Logical Addressing (IP)
🗺️ Routing
📦 Packet Forwarding
🧭 Path Determination
🔀 Fragmentation
🌐 Subnetting

Examples

IPv4 / IPv6 Addressing Router Packet Forwarding ICMP (Ping, Traceroute) OSPF, BGP Routing Protocols NAT (Network Address Translation)

Protocols

IPv4 IPv6 ICMP OSPF BGP RIP IPSec
2

Data Link Layer

PDU: Frames

Physical Addressing Layer — Provides node-to-node data transfer and handles error detection from the physical layer. Uses MAC addresses to identify devices on the same local network.

Key Functions

🏷️ Physical (MAC) Addressing
📐 Framing / Frame Creation
🔍 Error Detection
🔄 Flow Control
🔀 Media Access Control
📊 Frame Synchronization

Sub-Layers

LLC (Logical Link Control) — IEEE 802.2 MAC (Media Access Control) — IEEE 802.3

Examples

Ethernet (802.3) Wi-Fi (802.11) Switch MAC Table Lookup PPP (Point-to-Point Protocol)

Protocols

Ethernet Wi-Fi PPP HDLC ARP Frame Relay
1

Physical Layer

PDU: Bits

Bit Transmission Layer — The hardware layer that deals with the physical transmission of raw bits over a communication channel. Converts data into electrical, optical, or radio signals.

Key Functions

🔌 Physical Connection
⚡ Bit Transmission
📊 Data Rate Control
➡️ Transmission Mode
📏 Signal Encoding
🔊 Topology (Bus, Star, Ring)

Transmission Modes

Simplex (One-way) Half-Duplex (Two-way, one at a time) Full-Duplex (Two-way simultaneous)

Examples

Ethernet Cables (Cat5, Cat6) Fiber Optic Cables USB Cables Hubs & Repeaters Bluetooth Physical Radio

Components

Cables (UTP, Fiber) Connectors (RJ45) Hubs Repeaters NIC

🌐 TCP/IP Model

What is the TCP/IP Model?

The TCP/IP (Transmission Control Protocol / Internet Protocol) Model is the practical, real-world networking model that powers the entire Internet. Developed by the U.S. Department of Defense (DARPA) in the 1970s, it has 4 layers and is what actually runs on every device connected to the Internet today.

Unlike OSI (a theoretical reference model), TCP/IP was built from real protocols that solve real networking problems. It's the reason the Internet works.

  • Developed by DARPA (Defense Advanced Research Projects Agency)
  • Protocol-oriented — based on real, working protocols
  • Used in practice — the actual Internet stack
  • 4 layers: Application, Transport, Internet, Network Access

TCP/IP 4 Layers

4 Application Layer → Messages
3 Transport Layer → Segments / Datagrams
2 Internet Layer → Packets
1 Network Access Layer → Frames → Bits

⚡ Quick Study — TCP/IP

L4 Application OSI layers 7+6+5 combined — HTTP, FTP, DNS, SMTP
L3 Transport End-to-end delivery — TCP (reliable) & UDP (fast)
L2 Internet Logical addressing & routing — IP, ICMP, ARP
L1 Network Access OSI layers 2+1 combined — Ethernet, Wi-Fi, cables

🔍 TCP/IP Layer Details
4

Application Layer

PDU: Messages | OSI Layers 7 + 6 + 5

The "Everything" Layer — Combines OSI's Application, Presentation, and Session layers into one. Handles all user-facing services, data formatting, encryption, and session management in a single layer.

What It Covers (from OSI)

📧 Application: Email, Web, FTP
🔐 Presentation: SSL/TLS, Encoding
🤝 Session: Connection Management
📦 Data Serialization

Key Protocols

HTTP / HTTPS FTP / SFTP SMTP / POP3 / IMAP DNS SSH / Telnet SNMP DHCP TLS / SSL

Real-World Examples

Browsing a website (HTTP/HTTPS) Sending an email (SMTP) Downloading files (FTP) Resolving domain names (DNS)
3

Transport Layer

PDU: Segments (TCP) / Datagrams (UDP)

End-to-End Communication — Same as OSI Transport Layer. Provides reliable (TCP) or fast/unreliable (UDP) delivery between applications on different hosts using port numbers.

Key Functions

✂️ Segmentation & Reassembly
📊 Flow Control (Sliding Window)
❌ Error Detection & Recovery
🔗 Connection-Oriented (TCP)
📡 Connectionless (UDP)
🔢 Port Multiplexing

TCP vs UDP

TCP — Reliable, ordered, connection-oriented
Web, Email, File Transfer, SSH UDP — Fast, lightweight, connectionless
Streaming, Gaming, DNS, VoIP
2

Internet Layer

PDU: Packets (Datagrams)

Logical Addressing & Routing — Same as OSI Network Layer. The heart of TCP/IP — handles addressing, routing, and packet forwarding across different networks using IP addresses.

Key Functions

📍 IP Addressing (IPv4/IPv6)
🗺️ Routing & Path Selection
📦 Packet Fragmentation
🔄 Packet Forwarding
🌐 Subnetting & CIDR
🛡️ IPSec Security

Key Protocols

IPv4 IPv6 ICMP ICMPv6 IPSec IGMP

Key Difference from OSI

Called "Internet Layer" (not Network) This is THE IP layer — what makes the Internet work
1

Network Access Layer

PDU: Frames → Bits | OSI Layers 2 + 1

The Hardware Layer — Combines OSI's Data Link and Physical layers. Handles everything about how data physically moves across the network — MAC addressing, framing, cables, signals.

What It Covers (from OSI)

🏷️ MAC Addressing (L2)
📐 Framing (L2)
🔌 Physical Cables (L1)
⚡ Signal Encoding (L1)
📡 Wireless (Wi-Fi, Bluetooth)
🔀 Error Detection (FCS/CRC)

Technologies

Ethernet (802.3) Wi-Fi (802.11) ARP PPP DSL Cable Modem Fiber (SONET)
