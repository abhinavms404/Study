A simple guide to how computers talk to each other over a network — broken into 7 easy-to-understand layers!

📡 What is the OSI Model?

Let's Understand the OSI Model

The OSI (Open Systems Interconnection) Model is like a rulebook that tells computers how to talk to each other over a network. It was made by a group called ISO (International Organization for Standardization) in 1984.

Think of it like this: imagine you want to send a letter to your friend. There are many steps — writing the letter, putting it in an envelope, adding an address, giving it to the post office, and so on. The OSI model does the same thing for computer data, but splits it into 7 simple steps (layers).

Each layer has its own job, and it only talks to the layer right above and below it — like a team where each person only helps the person directly next to them.

  • It gives us a common language so everyone understands how networking works
  • Different companies can build different parts, and they all work together
  • Makes it easier to fix problems — you know which layer to check!
  • It's a reference model — a learning tool, not something that runs directly on your computer

🔍 Layer Details & Examples
7

Application Layer

PDU: Data ഒന്ന് · ആപ്ലിക്കേഷൻ ലെയർ

The "What You See" Layer — This is the layer YOU directly use! When you open a website, send an email, or chat with friends online — that's the Application Layer doing its job.

മലയാളം: നമ്മൾ ഉപയോഗിക്കുന്ന ആപ്പുകൾ

What Does It Do?

📧 Lets you send emails
🌐 Lets you browse websites
📁 Lets you transfer files
🖥️ Lets you access computers remotely
💬 Lets you chat & message
🖨️ Lets you print over a network

Real-Life Examples

Email (SMTP, IMAP, POP3) Web Browsing (HTTP/HTTPS) File Transfer (FTP, SFTP) DNS (turns google.com into an address) Telnet / SSH (remote login)

Protocols (Rules It Uses)

HTTP HTTPS FTP SMTP POP3 IMAP DNS SNMP SSH
6

Presentation Layer

PDU: Data രണ്ട് · പ്രസന്റേഷൻ ലെയർ

The "Translator" Layer — Converts data into a format the other side can understand, and also keeps your data safe by encrypting it.

മലയാളം: വിവരങ്ങളുടെ രൂപം മാറ്റുന്നത്

What Does It Do?

🔄 Translates data formats
🔐 Encrypts data (scrambles it for safety)
🔓 Decrypts data (unscrambles it)
🔤 Converts character encoding (ASCII, UTF-8)
📦 Compresses data (makes it smaller)
📂 Decompresses data (makes it normal again)

Real-Life Examples

SSL/TLS (lock icon in your browser = encryption!) JPEG, GIF, PNG (image formats your phone can read) ASCII, UTF-8 (ways to represent letters as numbers) MPEG (video compression so YouTube loads faster) ZIP files (compressing data to save space)

Protocols (Rules It Uses)

SSL TLS JPEG MPEG GIF PNG ASCII EBCDIC
5

Session Layer

PDU: Data മൂന്ന് · സെഷൻ ലെയർ

The "Phone Call Manager" Layer — Opens a session, keeps it running, and closes it when done.

മലയാളം: ഡാറ്റാ കൈമാറ്റത്തിന്റെ സമയം നോക്കുന്നത്

What Does It Do?

🤝 Opens a session (like dialing a call)
🔄 Keeps the session alive (like staying on the call)
🔑 Checks who you are (authentication)
🛡️ Checks what you're allowed to do (authorization)
❌ Closes the session (like hanging up)
📊 Keeps data in sync (checkpointing)

Real-Life Examples

NetBIOS Sessions (computer-to-computer talks) RPC (Remote Procedure Call — like a remote control for programs) PPTP (VPN tunnel for secure connections) Video call sessions (Zoom, Google Meet) Database connections (apps talking to data)

Protocols (Rules It Uses)

NetBIOS RPC PPTP SAP SDP
4

Transport Layer

PDU: Segments (TCP) / Datagrams (UDP) നാല് · ട്രാൻസ്പോർട്ട് ലെയർ

The "Delivery Person" Layer — This layer makes sure your data actually gets from your computer to the right destination.

മലയാളം: ഡാറ്റയെ ചെറിയ ഭാഗങ്ങളാക്കുന്നത്

What Does It Do?

✂️ Breaks big data into small pieces (segments)
📊 Controls how fast data flows
❌ Catches and fixes errors
🔗 TCP = reliable delivery (like registered post)
📡 UDP = fast delivery (like regular post, no tracking)
🔄 Makes sure segments arrive in order

TCP vs UDP — Which One When?

TCP — Reliable, checks every packet arrives
Used for: Web, Email, File download UDP — Fast, no checking, just sends
Used for: Streaming, Gaming, Video calls, DNS

Fun fact: TCP does a "three-way handshake" (SYN → SYN-ACK → ACK) — like saying "Hey!" "Hey back!" "OK let's talk!" before sending data.

Protocols (Rules It Uses)

TCP UDP SCTP DCCP
3

Network Layer

PDU: Packets അഞ്ച് · നെറ്റ്‌വർക്ക് ലെയർ

The "GPS Navigator" Layer — Figures out the BEST PATH for your data using IP addresses.

മലയാളം: ഡാറ്റ എത്തുന്ന വഴി കണ്ടെത്തുന്നത്

What Does It Do?

📍 Assigns IP addresses (like home addresses)
🗺️ Finds the best route (like GPS navigation)
📦 Forwards packets to the next stop
🧭 Chooses the path data should travel
🔀 Splits big packets into smaller ones
🌐 Divides networks into sub-networks

Real-Life Examples

IPv4 Address (192.168.1.1 — like a house address) IPv6 Address (newer, way more addresses) Router forwarding your data to the right place Ping (testing if a computer is reachable) Traceroute (showing the path your data takes) NAT (sharing one IP among many devices)

Protocols (Rules It Uses)

IPv4 IPv6 ICMP OSPF BGP RIP IPSec
2

Data Link Layer

PDU: Frames ആറ് · ഡാറ്റാ ലിങ്ക് ലെയർ

The "ID Card Checker" Layer — Uses MAC addresses to identify devices on the same local network.

മലയാളം: തെറ്റുകൾ കൂടാതെ ഡാറ്റ കൈമാറുന്നത്

What Does It Do?

🏷️ Uses MAC addresses (like a serial number for your network card)
📐 Creates frames (wraps data with headers)
🔍 Detects errors in transmission
🔄 Controls flow between two nearby devices
🔀 Manages who gets to send data when
📊 Keeps frames synchronized

Two Sub-Layers

LLC (Logical Link Control) — manages the link MAC (Media Access Control) — manages who sends when

Real-Life Examples

Ethernet (your wired internet cable) Wi-Fi (wireless connection) Switch looking up MAC addresses PPP (Point-to-Point — direct connection)

Protocols (Rules It Uses)

Ethernet Wi-Fi PPP HDLC ARP Frame Relay
1

Physical Layer

PDU: Bits ഏഴ് · ഫിസിക്കൽ ലെയർ

The "Wires and Signals" Layer — Deals with actual physical stuff — cables, connectors, electrical signals.

മലയാളം: കേബിളുകൾ വഴി ഡാറ്റ കൊണ്ടുപോകുന്നത്

What Does It Do?

🔌 Physical connection (plugging in cables)
⚡ Sends bits as electrical/optical signals
📊 Controls how fast data is sent
➡️ Determines send/receive direction
📏 Converts data to signals (encoding)
🔊 Defines network shape (topology)

Types of Transmission

Simplex (one-way only, like a radio) Half-Duplex (two-way, one at a time, like a walkie-talkie) Full-Duplex (two-way at once, like a phone call)

Real-Life Examples

Ethernet cables (Cat5, Cat6 — the ones you plug into your router) Fiber optic cables (super fast, uses light!) USB cables Hubs & Repeaters (boost signals) Bluetooth (wireless signals)

Hardware (Physical Stuff)

Cables (UTP, Fiber) Connectors (RJ45) Hubs Repeaters NIC (Network Card)

🌐 TCP/IP Model

What is the TCP/IP Model?

The TCP/IP (Transmission Control Protocol / Internet Protocol) Model is the REAL networking model that actually runs the Internet! While OSI is a theory-based model you study in school, TCP/IP is what your phone, laptop, and every website actually uses.

It was built by DARPA (a U.S. government research group) in the 1970s. They needed a practical system for computers to talk to each other — and they created the model that became the backbone of the Internet.

The big difference? TCP/IP has only 4 layers (instead of OSI's 7), because it combines some layers together to keep things simple and practical.

  • Built by DARPA (Defense Advanced Research Projects Agency) in the 1970s
  • It's based on real protocols — not just a theory
  • It's what actually runs the Internet today
  • 4 layers: Application, Transport, Internet, Network Access

TCP/IP 4 Layers

4 Application Layer → Messages
3 Transport Layer → Segments / Datagrams
2 Internet Layer → Packets
1 Network Access Layer → Frames → Bits

⚡ Quick Study — TCP/IP

L4 Application Combines OSI layers 7+6+5 — all your apps (HTTP, FTP, DNS, SMTP)
L3 Transport Delivers data — TCP (reliable, like registered post) & UDP (fast, like regular post)
L2 Internet Uses IP addresses to route data — the GPS of networking
L1 Network Access Combines OSI layers 2+1 — cables, Wi-Fi, signals, MAC addresses

🔍 TCP/IP Layer Details
4

Application Layer

PDU: Messages | Combines OSI Layers 7 + 6 + 5

The "Everything App" Layer — In TCP/IP, this ONE layer does the job of THREE OSI layers (Application + Presentation + Session). It handles all your apps, data formatting, encryption, and connection management in one place.

What It Covers (from OSI)

📧 From Application: Email, Web, FTP
🔐 From Presentation: SSL/TLS, Encoding
🤝 From Session: Connection Management
📦 From Presentation: Data Formatting

Key Protocols (Rules It Uses)

HTTP / HTTPS FTP / SFTP SMTP / POP3 / IMAP DNS SSH / Telnet SNMP DHCP TLS / SSL

Real-Life Examples

Browsing a website (HTTP/HTTPS) Sending an email (SMTP) Downloading files (FTP) Turning google.com into an IP address (DNS)
3

Transport Layer

PDU: Segments (TCP) / Datagrams (UDP)

The "Delivery Person" Layer — Same as OSI's Transport Layer. Makes sure your data gets delivered — either reliably (TCP) or quickly (UDP). It uses port numbers to know which app should receive the data.

What Does It Do?

✂️ Breaks data into segments
📊 Controls data flow speed
❌ Catches errors
🔗 TCP = reliable (checks every packet)
📡 UDP = fast (just sends, no checking)
🔢 Uses port numbers (like apartment numbers)

TCP vs UDP — Simple Guide

TCP — Reliable, like registered post with tracking
Used for: Web pages, Emails, File downloads UDP — Fast, like dropping a letter in a mailbox
Used for: Video streaming, Online gaming, DNS lookups
2

Internet Layer

PDU: Packets (Datagrams)

The "GPS of Networking" — Same as OSI's Network Layer. This is THE most important layer of TCP/IP because it's where IP (Internet Protocol) lives! It figures out how to get your data from your computer to any other computer in the world.

What Does It Do?

📍 Gives devices IP addresses
🗺️ Finds the best route for data
📦 Breaks packets into smaller pieces if needed
🔄 Forwards packets hop by hop
🌐 Handles IPv4 and IPv6
🛡️ IPSec for security

Key Protocols (Rules It Uses)

IPv4 IPv6 ICMP ICMPv6 IPSec IGMP

Why It's Special

Called "Internet Layer" (not Network like in OSI) This is where IP lives — THE protocol of the Internet!
1

Network Access Layer

PDU: Frames → Bits | Combines OSI Layers 2 + 1

The "Physical Stuff" Layer — In TCP/IP, this ONE layer does the job of TWO OSI layers (Data Link + Physical). It handles everything physical — cables, Wi-Fi, MAC addresses, framing, and sending bits as signals.

What It Covers (from OSI)

🏷️ From Data Link: MAC Addressing
📐 From Data Link: Framing
🔌 From Physical: Cables & Connectors
⚡ From Physical: Signal Encoding
📡 Wireless (Wi-Fi, Bluetooth)
🔀 Error Detection (FCS/CRC)

Technologies Used

Ethernet (802.3) Wi-Fi (802.11) ARP PPP DSL Cable Modem Fiber (SONET)

OSI vs TCP/IP — What's the Difference?

What We Compare OSI Model (Study Model) TCP/IP Model (Real Model)
Number of Layers 7 layers 4 layers (some merged together)
Who Made It? ISO (a standards group) in 1984 DARPA (U.S. govt research) in 1970s
Why Was It Made? To teach how networking works (theory) To actually build the Internet (practice)
How Was It Built? Protocol-independent (generic rules) Built around real, working protocols
Where Is It Used? Schools, exams, troubleshooting guides Every device on the Internet right now
Session & Presentation? Have their own separate layers (5 & 6) Merged into the Application layer
Reliability Reliability guaranteed at Transport layer Up to you — TCP is reliable, UDP is not
